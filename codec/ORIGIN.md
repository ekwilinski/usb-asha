# libg722 encoder

Encoder sources from [sippy/libg722 v1.2.8](https://github.com/sippy/libg722/tree/4c2e79c5cbcb5ee12a97a16002a073ac83396480), commit `4c2e79c5cbcb5ee12a97a16002a073ac83396480`. The SONNET edition adds an eight-codeword, four-path upper-band search. The generic edition uses the upstream quantizer. The PCM and generic reference frames in tests/fixtures come from the upstream 64 kbit/s, 16 kHz codec test. The SONNET reference frames were generated from the same PCM with a separate host implementation of the four-path search. Copyright notices are retained in each file and `LICENSE`.
