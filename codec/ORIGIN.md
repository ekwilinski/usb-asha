# libg722 encoder

Unmodified encoder sources from [sippy/libg722 v1.2.8](https://github.com/sippy/libg722/tree/4c2e79c5cbcb5ee12a97a16002a073ac83396480), commit `4c2e79c5cbcb5ee12a97a16002a073ac83396480`. The firmware compiles these sources directly. The two reference frames in tests/fixtures come from the upstream 64 kbit/s, 16 kHz codec test. Copyright notices are retained in each file and `LICENSE`.
